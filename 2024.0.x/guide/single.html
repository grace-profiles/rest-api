1 Introduction

Grace Profiles encapsulate project commands, templates, and plugins.

To create an application using the rest-api profile you can use the next command:

$ grace create-app com.example.myapp --profile=rest-api

3 Upgrade

Currently, Grace framework does not provide a direct upgrade command, but it may offer this in the future.

The simplest way is to create two different versions of a new application, and then compare the differences between the two versions using the git-diff command.

$ sdk use grace 2024.0.0-SNAPSHOT
$ grace -v
$ grace create-app com.example.myapp --profile=rest-api --grace-version=2023.3.0
$ cd myapp
$ git init && git add . && git commit -m "Generated by Grace 2023.3.0"
$ cd ..
$ grace create-app com.example.myapp --profile=rest-api --force
$ cd myapp
$ git diff
