== create-integration-test

=== Description

Creates an Integration Test.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Integration Test Name
|The name of the Integration Test
|true
|===

=== Flags

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Type**

|force
|Whether to overwrite existing files
|boolean, default: false
|===

=== Usage

[source,bash]
----
$ grace create-integration-test [Test Name]
----
