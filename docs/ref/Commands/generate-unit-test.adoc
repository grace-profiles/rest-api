== generate-unit-test

=== Description

Generates a Unit Test for a controller that performs REST operations.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Domain Class
|The name of the Domain Class
|true
|===

=== Flags

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Type**

|force
|Whether to overwrite existing files
|boolean, default: false
|===

=== Usage

[source,bash]
----
$ grace generate-unit-test [Domain Class]
----

=== Examples

[source,bash]
----
$ grace generate-unit-test Post
| Rendered template Spec.groovy to destination src/test/groovy/com/example/PostControllerSpec.groovy
| Scaffolding completed for app/domain/com/example/Post.groovy
----
