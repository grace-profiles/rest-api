== create-restful-controller

=== Description

Creates a REST Controller.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Domain Class
|The name of the Domain Class
|true
|===

=== Flags

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Type**

|force
|Whether to overwrite existing files
|boolean, default: false
|===

=== Usage

[source,console]
----
$ grace create-restful-controller [Domain Class]
----

=== Examples

[source,console]
----
$ grace create-restful-controller Post
| Created app/controllers/com/example/PostController.groovy
----
