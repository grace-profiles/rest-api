== create-service

=== Description

Creates a Service.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Service Name
|The name of the command to be created
|true
|===

=== Flags

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Type**

|force
|Whether to overwrite existing files
|boolean, default: false
|===

=== Usage

[source,bash]
----
$ grace create-service [Service Name]
----
