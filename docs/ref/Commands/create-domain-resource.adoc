== create-domain-resource

=== Description

Creates a Domain Class that represents a resource.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Resource Name
|The name of the Resource
|true
|===

=== Flags

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Type**

|force
|Whether to overwrite existing files
|boolean, default: false
|===

=== Usage

[source,bash]
----
$ grace create-domain-resource [Resource Name]
----
