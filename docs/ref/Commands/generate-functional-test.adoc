== generate-functional-test

=== Description

Generates a Functional Test for a controller that performs REST operations.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Domain Class
|The name of the Domain Class
|true
|===

=== Flags

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Type**

|force
|Whether to overwrite existing files
|boolean, default: false
|===

=== Usage

[source,bash]
----
$ grace generate-functional-test [Domain Class]
----

=== Examples

[source,bash]
----
$ grace generate-functional-test Post
| Rendered template FunctionalSpec.groovy to destination src/integration-test/groovy/com/example/PostFunctionalSpec.groovy
| Scaffolding completed for app/domain/com/example/Post.groovy
----
