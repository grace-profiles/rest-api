== generate-all

=== Description

Generates a Controller that performs CRUD operations and the associated views.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Domain Class
|The name of the Domain Class
|true
|===

=== Flags

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Type**

|force
|Whether to overwrite existing files
|boolean, default: false
|===

=== Usage

[source,bash]
----
$ grace generate-all [Command Name]
----
